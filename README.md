# 先听十分钟 · English First

每天第一次打开浏览器，先听十分钟英语。听满以后可以继续看，播放页不会自动关掉。边看边遇到的新词，可以在同一页学、测、复习。

## 安装与开始

1. 下载并解压仓库。打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`，开启开发人员模式。
2. 点「加载解压缩的扩展」，选择含 `manifest.json` 的目录。不需要运行安装脚本。
3. 点扩展图标，展开「素材与字幕」，导入自己的 MP4 或 WebM。视频原长至少 8 分 30 秒；导入英文 SRT 或 VTT 后才会生成词单，压在画面里的字幕无法读取。
4. 按需设置启动提醒、指定网站或全站模式。全站模式需要你主动批准访问 HTTP(S) 网页的权限。没导入可播放视频时不会拦截；扩展管理页仍能打开。

## 听力和词汇怎么用

- **听力计时：**只有在前台、有声音地播放才累计实际时间。暂停、切走、静音或拖动不算；播放速度不会缩短十分钟目标。当天听满后不再重复拦截；浏览器窗口一直开着跨午夜也不会突然打断。
- **今日词单：**扫描一整段视频的英文字幕，默认最多选 12 项，优先匹配内置备考词表，也可补入部分视频主题词。已学或熟悉的词不会重复作为新词推荐。
- **测验与复习：**支持英译中、中译英和字幕填空。学过或标为熟悉的词按计划复习，答错的词提前再练。中文同义答案可自行判定。
- **布局与主题：**宽窗口左侧看视频、右侧学词；窄窗口自动改成上下排列。可以切换五套主题。

## 每天的视频从哪里来？

默认模式不联网选片，也没有内置私人推荐任务。开启可选 AI 脚本后可自动联网找片，见下文。导入的几段视频可按天轮换。视频和字幕原样保存在本地，扩展不会压缩或上传素材，也不会上传你的学习记录。源码不随附视频。

可选的本地推荐文件供外部任务对接；不配置也能正常使用。不要提交推荐历史、本地视频或个人配置。

## 可选：AI 每日自动找视频、选词

安装 Node.js 22+ 和 FFmpeg（让 `ffprobe` 可用），在本机环境变量中配好 `EF_AI_MODEL` 和 `EF_AI_API_KEY`。模型接口默认 `https://api.openai.com/v1`，可通过 `EF_AI_BASE_URL` 换成你信任的 Chat Completions 兼容服务。可用 `EF_AI_TOPIC` 写主题偏好，`EF_AI_LEVEL` 设置英语水平（默认 B1–B2）。

- **立即试跑：**在扩展目录运行 `node ai-daily.mjs`，再启动浏览器。**不用配置或更新视频库。**
- **每天自动：**在 Windows 任务计划程序中一次性设置每天晚间运行 `node ai-daily.mjs --tomorrow`。操作的「程序」填 `node.exe` 的完整路径，「参数」填 `ai-daily.mjs --tomorrow`，「起始于」填扩展目录。任务要在能读取上述环境变量的账号下运行。先手动试跑一次再启用任务，建议启用「错过计划后尽快运行」。已经准备好某天的素材时不会再次调用模型。不要把密钥放进代码、Git 或任务的参数。
- **选片：**默认不限主题，模型会在美食、音乐、历史、旅行、体育、影视、日常、科普等主题间换着找。脚本实时查 [PeerTube 联合搜索](https://sepiasearch.org/)、[NASA SVS](https://svs.gsfc.nasa.gov/help/)和 [NOAA Ocean Today](https://oceantoday.noaa.gov/sitemap.xml)。PeerTube 仅使用受支持的公开站点，要求发布者允许下载、注明 CC BY 或 CC BY-SA，并提供英文字幕。其他来源也必须有配套英文字幕和媒体直链。模型在查到的结果中排序，不负责生成网址。脚本校验实际音视频、时长和字幕，再保存发布方提供的文件，不在本机转码。新视频优先，最近三条尽量不重复；候选不足时只会从能验证的来源中找，不保证每天都有新的内容。
- **选词：**模型从当日视频英文字幕的候选里挑词，扩展再用实际字幕核对，过滤已学或已标熟悉的词。测验和间隔复习仍在本地。找不到合适素材时回到已导入的本地视频；仅 AI 选词失败时，仍正常播放，并用本地词单。

可选的手动目录仍兼容：`node ai-daily.mjs ai-catalog.local.json`。它不是自动找片的前置条件。自动和手动模式都只接受 8:30–60:00、至多 160 MiB 的 MP4/WebM，以及至多 256 KiB 的英文 VTT。YouTube 普通播放页不能用作素材直链。

模型服务会收到主题偏好、候选信息和部分英文字幕片段，不会收到原视频、密钥以外的任何登录资料、文件路径、浏览或学习记录。素材站点不会收到模型密钥；生成文件也不会提交到 Git。不要用你不愿发送给模型服务的私人字幕。API 可能产生费用。未启用 AI 时，不影响扩展原有离线用法。
