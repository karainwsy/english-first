# 先听十分钟 · English First

每天第一次打开浏览器，先听十分钟英语。听满以后可以继续看，播放页不会自动关掉。边看边遇到的新词，可以在同一页学、测、复习。

## 安装与开始

1. 下载并解压仓库。打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`，开启开发人员模式。
2. 点「加载解压缩的扩展」，选择含 `manifest.json` 的目录。不需要运行安装脚本。
3. 点扩展图标，展开「素材与字幕」，导入自己的 MP4 或 WebM。视频原长至少 8 分 30 秒；导入英文 SRT 或 VTT 后才会生成词单，压在画面里的字幕无法读取。
4. 按需设置启动提醒、指定网站或全站模式。全站模式需要你主动批准访问 HTTP(S) 网页的权限。没导入可播放视频时不会拦截；扩展管理页仍能打开。

## 听力和词汇怎么用

- **听力计时：**只有在前台、有声音地播放才累计实际时间。暂停、切走、静音或拖动不算；播放速度不会缩短十分钟目标。当天听满后不再重复拦截；浏览器窗口一直开着跨午夜也不会突然打断。
- **今日词单：**扫描一整段视频的英文字幕，默认最多选 12 项，优先匹配内置备考词表，也可补入部分视频主题词。已学或熟悉的词不会重复作为新词推荐。
- **测验与复习：**支持英译中、中译英和字幕填空。学过或标为熟悉的词按计划复习，答错的词提前再练。中文同义答案可自行判定。
- **布局与主题：**宽窗口左侧看视频、右侧学词；窄窗口自动改成上下排列。可以切换五套主题。

## 每天的视频从哪里来？

默认模式不联网选片，也没有内置私人推荐任务。可选 AI 脚本见下文。导入的几段视频可按天轮换。视频和字幕原样保存在本地，扩展不会压缩或上传素材，也不会上传你的学习记录。源码不随附视频。

可选的本地推荐文件供外部任务对接；不配置也能正常使用。不要提交推荐历史、本地视频或个人配置。

## 可选：AI 每日选片与选词

不启用 AI 时，扩展仍可离线轮换本地视频、用原来的方法生成词单。启用需要 Node.js 22+ 和 PATH 里的 FFmpeg（使用 `ffprobe` 验证时长）。不增加浏览器权限，也不把 API 密钥存进扩展。

1. 复制 `ai-catalog.example.json` 为 `ai-catalog.local.json`，填写至少两条你有权使用的视频及对应英文 WebVTT。支持本地路径或发布方直连 HTTPS MP4/WebM 和 VTT，不支持把普通网页或 YouTube 播放页当视频地址。单条视频 8:30–60:00，最多 128 MiB；字幕最多 256 KiB。原片原样保存，不转码。
2. 在运行脚本的环境中设置 `EF_AI_MODEL` 和 `EF_AI_API_KEY`。可用 `EF_AI_BASE_URL` 指定你信任的兼容 Chat Completions 接口（默认 `https://api.openai.com/v1`），`EF_AI_LEVEL` 默认 B1–B2。密钥别放进目录、脚本或 Git；服务商可能按调用收费。
3. 在扩展目录里运行 `node ai-daily.mjs ai-catalog.local.json`，再开启浏览器。也可在 Windows 任务计划程序里用同一个命令加 `--tomorrow`，每晚提前准备次日素材（“起始于”设为扩展目录）。同一天已生成时不会再次调用模型。脚本没运行、电脑离线或模型没选出有效视频时，扩展仍可继续使用本地备用素材。

可以先用 ai-catalog.starter.json 试跑 NOAA 的原始英文视频和字幕。它只有一条，若想让 AI 在多条之间选择，请按示例添加候选。公开仓库不附带下载的视频文件。

AI 从你配置的候选里挑一部，有多条时避开上一部；不在全网自由搜索，不接受模型编造的 URL。AI 只从真实英文字幕抽出的候选里选词；浏览器再按实际字幕核对，并过滤已学和已标熟悉的词。释义、测验和间隔复习仍在本地。若 AI 只在选词这一步失败，视频照常使用，词单回退到本地规则。

模型服务会收到候选标题、时长、主题、难度及选中视频的部分英文字幕行，不会收到视频、文件路径、浏览或学习记录。下载素材时不会向素材主机发送模型密钥。不要使用你不愿发送给模型服务的私人字幕。自动生成的推荐文件和媒体不应提交到 Git。
